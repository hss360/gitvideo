#Now after adding the files to the folder- we need to insert our memory-card, initalise our project - while we're in our root folder
git init


#How do we save, we use this function "git add"- we can either add everything or a specific list
git add . (this saves everything from the last time i saved)
git add index.html (this would just save the index.html changes)
#This is like putting these changes to the staging area


#After the staging area we need to permanently save them as new immutable snapshot so we commit
git commit -m 'adding index.html and main.py file'


#Imagine now we are removing our index.html file and apping an app.js file
rm index.html
touch app.js
git add .
git commit -m 'Deleting index.html file and adding app.js'
#Once again this removes index.html, adds app.js and includes all of the changes to the staging area. Then commits
